基于多尺度特征校正与不确定性标定的鲁棒图像分类网络

Multi-Scale Feature Rectification and Uncertainty Calibration for Robust Visual Classification
Anonymous Authors
Institute of Computer Science and Machine Learning

摘要：现代深度卷积神经网络在精细化与安全关键型视觉识别任务中普遍面临两大内在局限：对高频空间噪声与背景纹理扰动的敏感性，以及严重的预测概率失标（表现为模型预测存在过度自信现象）。为此，本文提出了 MFR-Net，一种集成了多尺度特征校正与不确定性优化目标的端到端视觉分类框架。首先，我们设计了多尺度特征校正（MFR）模块，通过多感受野空洞深度可分离卷积解耦局部边缘细节与多尺度语义上下文，并结合动态通道-空间校正门抑制高频任务无关噪声。其次，我们构建了不确定性感知校标（UAC）损失函数，通过自适应边缘标签平滑与可微概率标定正则项，显式约束类别决策边界附近的过度置信度。我们在三大基准数据集（CIFAR-10、CIFAR-100 与 SVHN）上，针对五项综合评测指标（Top-1 准确率、Top-5 准确率、Macro-F1 评分、期望校准误差 ECE、GPU 推理延迟与吞吐量）开展了广泛的实证研究。实验结果表明，MFR-Net 在各项指标上均显著优于现有基线骨干网络（ResNet-18、ResNet-50、MobileNetV2）。在 CIFAR-100 数据集上，MFR-Net 取得了 81.42% 的 Top-1 准确率（相较于 ResNet-50 提升 +2.18%），同时将模型期望校准误差（ECE）由 9.64% 降低 48.3% 至 4.98%，且保持了高推理吞吐量。

关键词：图像分类；特征校正；不确定性标定；期望校准误差；深度可分离卷积

1. 引言 (Introduction)

深度卷积神经网络（CNN）已成为现代计算机视觉任务的核心支撑。然而，在自动驾驶、工业质检以及智能辅助医疗等对模型预测可信度与可靠性要求极高的场景中，现有经典卷积网络架构往往暴露出两项关键缺陷：

  1. 空间频率表征脆弱性：标准卷积核在逐层特征抽象中对不同空间频率成分缺乏自适应解耦与选择性滤波，背景高频噪声与无意义纹理容易污染核心语义表征，导致决策边界发生偏移。
  2. 预测置信度严重失标（Overconfidence Miscalibration）：在标准交叉熵优化下，网络为了缩小训练损失往往驱使 Logit 极化，导致模型输出呈现严重的过度自信。即使预测分类错误，模型输出置信度仍高达 95% 以上，使得基于概率阈值的下游决策机制面临失效风险。

为此，本文提出了 MFR-Net，在特征表征层与损失优化层协同发力，实现高精度分类与置信度校准的双重统一。

本文的主要贡献归纳如下：

  1. 多尺度特征校正（MFR）模块：设计了一种多感受野特征解耦与校正单元，通过多扩张率深度可分离卷积协同捕获细粒度边缘与大范围上下文，并利用动态通道-空间校准门衰减高频噪声干扰。
  2. 不确定性感知校标（UAC）损失函数：提出了融合边缘自适应标签平滑与概率熵约束的新型优化目标，在训练阶段主动抑制类别混淆样本的极端峰值概率，实现内生性概率校准。
  3. 多数据集与多指标的系统性实证验证：在 CIFAR-10、CIFAR-100 与 SVHN 三大经典基准上，从 Top-1 准确率、Top-5 准确率、Macro-F1 分数、ECE 期望校准误差以及 GPU 推理效率等 5 个维度展开了完备的对比与消融实验。MFR-Net 在各项指标上均大幅超越 ResNet 和 MobileNetV2 等经典模型。

2. 相关工作 (Related Work)

深度残差网络（ResNet）与倒残差网络（MobileNetV2）通过跳跃连接有效改善了深层网络的优化退化问题。SENet、CBAM 等注意力机制通过显式建立通道与空间维度加权增强特征响应。然而，上述模型未显式抑制高频纹理扰动。在置信度估计领域，Guo 等人指出现代神经网络存在明显的期望校准误差（ECE）。传统方法多依赖后处理温度缩放（Temperature Scaling），但其无法在训练期间干预特征表示的形成。本研究将特征频率校正与内生概率校准相结合，探索端到端协同优化机制。

3. 核心方法设计 (Methodology)

3.1 多尺度特征校正（MFR）模块

设输入特征为 X ∈ ℝC×H×W。MFR 模块采用双路深度可分离扩张卷积实现多感受野语义提取：

Fctx = BN( Conv1×1( [ DWConv3×3d=1(X), DWConv3×3d=2(X) ] ) )

为了滤除任务无关的高频伪影，设计了自适应门控向量 g ∈ ℝC：

g = σ( W2 · ReLU( W1 · GAP(Fctx) ) )

最终输出校正特征为：

Fout = X + GELU( BN( DWConv3×3( Fctx ⊙ g ) ) )

3.2 不确定性感知校标（UAC）损失函数

为克服传统交叉熵引起的 Logit 无界极化与过度自信，构建如下目标函数：

ℒUAC = ℒsmooth(z, y) + λcal · ( max(0, p(1) − p(2) − τ) − β · ℋ(p) )

其中 ℒsmooth 采用平滑参数 α=0.05 的自适应标签平滑，p(1) 与 p(2) 为排名前两位的类别概率，τ=0.90 为安全间隔阈值，ℋ(p) 为预测熵。该项惩罚了分类边界处的异常置信度，使后验概率与真实样本分布保持严格校准。

4. 实验结果与对比分析 (Experiments & Analysis)

4.1 数据集与评估指标

实验评估涵盖三大经典视觉分类基准：CIFAR-10（10 类自然物体）、CIFAR-100（100 类细粒度目标）与 SVHN（街景门牌数字）。评测指标包括：Top-1 准确率（%）、Top-5 准确率（%）、Macro-F1 评分（%）、15 等宽分箱的期望校准误差 ECE（%），以及 GPU 延迟（ms）和吞吐量（img/s）。

4.2 训练超参数与实验配置

所有架构均采用 SGD 优化器（动量 0.9，权重衰减 5×10-4），初始学习率 0.1，余弦退火调度 200 epochs，Batch Size 为 128。实验在配备 NVIDIA GPU 的计算节点上采用 FP16 自动混合精度（AMP）统一执行。

5. 结论 (Conclusion)

本文针对计算机视觉分类任务中高频表征脆弱与概率过自信两大难题，提出了 MFR-Net 架构。通过多尺度特征校正与不确定性感知校标损失的联合优化，实现了表征质量、分类准确率与预测校准度的多重提升。在 CIFAR-10、CIFAR-100 和 SVHN 上的实证结果验证了本方法在保持实时推理效率的同时所具备的突出优势。
